01 / The problem

Monitoring alarms one sensor at a time, and always too late.

A closed living system — a fish farm, a wetland, a bioreactor, a habitat in space — is a loop that quietly wants to fail. The instruments watching it foul and drift, so the dashboard looks calm while the system collapses. Conventional monitoring reacts after a single gauge crosses a line. By then the loss has happened.

Terra models the whole coupled system instead of one channel. It recovers the hidden state no sensor can read, quantifies its own uncertainty, and forecasts the breach hours ahead — early enough to prevent it, not just record it.

02 / The engine

It infers what it cannot measure, and knows how much it doesn't know.

A recursive Bayesian estimator (an unscented Kalman filter) predicts the system forward, corrects on each noisy reading, and reports the hidden state with a calibrated 95% credible band. 03 / The instrument

Signal to action, on one page.

Cheap probes into an offline edge node running the engine, into a forecast, into an uncertainty-gated decision, into a real actuator. The cloud coordinates the fleet; it is never in the safety path.

04 / Autonomy

It acts unattended only when it trusts its own estimate.

A forecast is only worth what you do with it. When breach risk crosses a trigger, the engine searches its actuators for the least aggressive action that clears the risk — and enacts it only if the estimate is confident. Otherwise it holds and hands the call to a human. That gate is what makes autonomy trustable.

05 / The network

Packets heal. So does the data.

Nodes form a self-healing wireless mesh to a gateway. When a link drops, traffic reroutes with no central controller. And because the engine models a spatially coupled field, a dropped node's state is imputed from its neighbours until it returns. Sever a link below and watch the route heal.

06 / The moat

Every deployment makes the next one better.

Each site calibrates the engine to its own biology and feeds a shared prior the whole fleet starts from. The defensibility is not a patent — it is the outcome-labeled failure data only Terra accumulates in the field.
